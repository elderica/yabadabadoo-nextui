Put a Sega Saturn BIOS in this folder (games won't start without one):
  sega_101.bin    (Japan v1.01, md5 85ec9ca47d8f6807718151cbcca8b964)
  mpr-17933.bin   (USA/Europe v1.00, md5 3240872c70984b6cbfda1586cab68dbe)

Games go in "Roms/Sega Saturn (SATURN)". Supported formats: .cue (with its
.bin files), .chd, .iso, .mds, .ccd, .m3u (multi-disc), .zip.
